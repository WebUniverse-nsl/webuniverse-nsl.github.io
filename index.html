01 / SYNTHESIS PIPELINE

From real software to verifiable training tasks.

WebUniverse constructs tasks, collects agent solutions in executable workspaces, and checks the delivered applications before selecting training data.

REAL SOURCES → TASKS

Construct tasks from repositories and web pages.

Extract application behavior from repository code and documentation to generate text-grounded tasks. Collect screenshots and supporting assets from real web pages to construct vision-grounded tasks.

Check the application the agent actually built.

Verification follows each task’s requirements. Functional behavior and visual fidelity use different checks.

Verification is followed by trajectory selection. We check conversation structure, image references, and compatibility with the training format. Failed attempts can supply workspaces and feedback for trajectory refinement.

The expanded v2 release includes all of v1 plus 5,347 additional trajectories. Exact 5K and 10K ablation subsets are available as ordered ID lists.
